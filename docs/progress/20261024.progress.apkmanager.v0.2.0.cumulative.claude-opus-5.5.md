## 1. Executive summary

In under three weeks ApkManager went from a documentation-only repository (Oct 6–7) to a **packaged, CI-built GTK 4 / Libadwaita desktop app** at version **0.2.0**:

- **Inspect:** open or drop an APK, list raw archive entries, run **Quick Manifest** or **Full Decode** through a pinned Apktool 2.9.3, and read package metadata on a **Properties** tab with the real app icon (PNG/WebP, adaptive and vector-drawable icons included).
- **Acquire:** **Get APKs** searches six sources (F-Droid, IzzyOnDroid, Aptoide, Uptodown, OpenAPK, APKMirror), downloads, and installs to a managed folder.
- **Integrate:** APK thumbnails and MIME type for file managers (Nemo/Nautilus), drag-and-drop install, show-in-file-manager, single-instance handling that replaces stale processes after reinstall.
- **Ship:** `.deb`, `.rpm`, Flatpak, Snap, and AppImage builds; all staging under `build/`, final packages in `dist/`; GitHub Actions run CI on PRs and build every package after a merge into `main`, publishing a Release on `v*` tags.
- **Sustain:** About window with linked credits and a **Donations** dialog (nine crypto wallets with QR codes, Ko-fi).

The 23 work commits on `main` arrived through **20 pull requests** (#1–#20) on `GreenfireInc/ApkManager`. Source is ~9,700 lines of Vala across 39 files (plus `build_info.vala.in`).

## 4. Features delivered

### 4.1 Core inspection (`src/core/`)

| Module | What it does |
|--------|--------------|
| `apk_archive.vala` | libarchive reader: list entries, read one entry, path-safety rules |
| `apktool_runner.vala` | Apktool subprocess: Quick Manifest (`-s -r --force-manifest`), Full Decode, cancel, merged stderr, framework dir `-p` |
| `decode_session.vala`, `decode_session_registry.vala` | Per-APK sessions persisted as JSON; cache under `~/.cache/apk-manager/decoded/<sha256>-manifest\|full/` with partial → final rename |
| `apk_metadata.vala` | Package, versions, SDKs, permissions, icon ref from decoded manifest + `apktool.yml` |
| `apk_display_name.vala` | Friendly app names from cached manifests |
| `apk_icon.vala` | Resource-ID resolution through `resources.arsc` (UTF-8/UTF-16 strings, extensionless entries); best-density bitmap selection |
| `apk_binary_xml.vala` | Android binary XML (AXML) parser — reads adaptive-icon and drawable XML without Apktool |
| `apk_vector_drawable.vala` | Renders Android `<vector>` drawables to PNG via Cairo (e.g. Brave's icon) |

### 4.2 Main window and sessions (`src/windows/main_window.vala`)

- AppManager-style split view: sidebar (search, menu, **heart / Donate**), content pane, footer status bar with Cancel.
- Recent APKs in **grid or list** view, sort menu, search filter, right-click menu (remove from list, delete from disk with confirmation).
- **Files** tab (raw ZIP entries) and **Properties** tab (metadata, icon, Quick Manifest / Full Decode buttons, File row that highlights the APK in the file manager over `org.freedesktop.FileManager1`).
- APK count button scans the install folder for APKs not yet in Recents.

### 4.3 Open, verify, install

| Window | Role |
|--------|------|
| `open_window.vala` | Pick or drop an APK; shows icon, size; drag onto install target |
| `verify_apk_window.vala` | SHA-256 verification |
| `install_confirm_dialog.vala` | Confirm install to `~/Applications/android` (configurable); optional remove-original |
| `core/apk_install.vala`, `core/apk_install_filename.vala` | Copy with canonical filenames; detect already-installed APKs |

### 4.4 Get APKs (`get_apks_window.vala`, `core/apk_store_search.vala`)

| Source | Search | Download |
|--------|--------|----------|
| F-Droid | ✓ | In-app |
| IzzyOnDroid | ✓ | In-app |
| Aptoide | ✓ | In-app |
| OpenAPK | ✓ | In-app |
| APKMirror | ✓ | In-app when not blocked by Cloudflare (detected and reported) |
| Uptodown | ✓ | Opens browser (site requires browser verification) |

Also: store icons in the source dropdown and result rows, version suffix `(v.X;YYYYMMDD)`, download confirmation (`get_apk_confirm_dialog.vala`), an install registry so results show *Installed* (`store_install_registry.vala`), and **Clear Store** in Preferences (`store_clearer.vala`, `clear_store_confirm_dialog.vala`).

Aurora OSS / Google Play was prototyped in PR #14 and **removed** at the owner's request; see [the Aurora explanation](../explanations/20261013.explanation.apkmanager.auroraoss.google-play.frontend.python.grok-4.7.md) and [the Python usage explanation](../explanations/20261015.explanation.apkmanager.python.usage.why-so-much.composer-2.5-fast.md).

### 4.5 File-manager integration (`core/file_manager_icons.vala`)

- `apk-manager --thumbnail …` CLI used by `data/com.github.ApkManager.thumbnailer.in` so Nemo/Nautilus show real app icons for `.apk` files.
- APK MIME definition under `data/mime/`.
- Opt-in icon extraction (`extract_apk_icons_info_dialog.vala`) controlled by the `file-manager-icon-mode` setting.

### 4.6 Preferences, shortcuts, About, Donations

| Window | Highlights |
|--------|------------|
| `preferences_window.vala` | Install path, remove-original, file-manager icon mode, preferred repository, runtime engine (Waydroid placeholder), update check, Clear Store |
| `keyboard_shortcuts_window.vala` | General, Recent APKs, APK details, Dialogs groups |
| `about_window.vala` | Version from `meson.build`; GPL-3.0; linked credits — **ApkManager** (GitHub, with GitHub icon), **AppManager**, **APKTool** |
| `donations_dialog.vala` | Nine wallets (BCH, BTC, LTC, ETH, DOGE, XTZ, LUNC, SOL, BNB) with coin icons; copy button; **QR popover** with coin logo centered; click an address to toggle a `TICKER://` prefix (row, popover label, and QR all follow); width measured so the prefix never reflows the row; Ko-fi row with wordmark → `ko-fi.com/greenfireinc` |
| `utils/qr_code.vala` | Dependency-free QR encoder (byte mode, ECC H, versions 1–10, penalty-based mask), checked against `qrencode` |

### 4.7 Single-instance robustness (`application.vala`, `main.vala`)

- `retire_stale_instance()` asks an older running binary to quit (or SIGTERMs it) so a fresh `meson install` takes effect.
- Stale `DBUS_SESSION_BUS_ADDRESS` sockets are ignored.
- `--version` is answered before GTK starts, so it works on headless machines and CI.

## 5. Build layout

| Path | Purpose |
|------|---------|
| `build/meson/` | Day-to-day developer Meson tree (`meson setup build/meson --prefix=$HOME/.local`) |
| `build/meson-debian/` | Meson tree used by `dpkg-buildpackage` |
| `build/meson-appimage/`, `build/AppDir/` | AppImage build tree and staging |
| `build/debian/` | Debian metadata (tracked); symlinked to `debian/` only during a `.deb` build |
| `build/snap/` | `snapcraft.yaml` + launcher (tracked) |
| `dist/` | Final packages (ignored by git) |

Everything else under `build/` is ignored by `.gitignore`.
