## 1. What you see

On the Install APK window, Orion, bitchat, Hulu, and Wine show their logos. Netflix and TikTok stay on the generic Android package symbol. There is no error dialog. **Inspect APK** still works.

Those two packages are also much larger (about 269 MiB and 331 MiB), so looking up the logo takes long enough to notice.

---

## 2. What that means

The logo is not stored as a loose `ic_launcher.png` the window can guess. `android:icon` is a resource id. The picture lives in `resources.arsc`, which maps that id to a path, and then that path is read out of the APK.

| APK | `resources.arsc` | Icon id | Files the table points at |
|-----|------------------|---------|---------------------------|
| Netflix | 19.4 MiB | `0x7f110000` | `res/raw/bqg` (WebP, no extension), plus an `anydpi` `.xml` |
| TikTok | 26.4 MiB | `0x7f0e0002` | `res/aq/a.png` |

Two checks in the loader rejected both apps:

1. `ApkArchive.read_entry()` refused any ZIP member larger than 8 MiB. Netflix and TikTok's resource tables are past that, so the icon id could not be resolved at all. Orion (379 KiB), bitchat (282 KiB), Hulu (1.3 MiB), and Wine (1.3 KiB) fit, which is why those logos already appeared.
2. Even with the table in memory, Netflix's raster files have no `.png` or `.webp` suffix (`res/raw/bqg` is a `RIFF....WEBP` blob). The scorer only kept paths ending in `.png`, `.webp`, `.jpg`, or `.jpeg`, so every Netflix density lost to “no image”.

---

## 3. Fix applied

`read_entry()` now allows an entry up to 64 MiB and copies each read in one slice instead of one byte at a time. That is enough for these resource tables and still refuses an unbounded member.

`ApkIcon` still prefers a real image extension. It also accepts an extensionless `res/` path, which is how shrunk Netflix builds store the WebP. Adaptive `.xml` icons stay excluded. GDK sniffs the bytes, so the missing suffix does not matter once the right member is chosen.

The Open APK window resolves the logo off the UI thread. If that is still running after 200 ms, a progress bar appears above **Inspect APK** and pulses until the logo (or the generic symbol, if there is no readable image) is ready. Faster APKs never show the bar.

Netflix then shows the red N. TikTok shows the note mark.

---

## 4. What you should run

Quit ApkManager, then rebuild and open one of the large packages:

```bash
cd ~/Workspace/Applications/apkManager
meson compile -C build
meson install -C build
export PATH="$HOME/.local/bin:$PATH"
apk-manager 00.references/netflix-9-87-1-build-9-74701.apk
```

The Install APK window should show the Netflix logo. The same for `00.references/tiktok-47-4-41.apk`. On these two, the progress bar above **Inspect APK** can appear briefly while the resource table is read.
