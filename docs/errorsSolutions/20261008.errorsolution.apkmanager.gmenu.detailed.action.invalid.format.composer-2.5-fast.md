## 1. What you see

Starting `apk-manager` aborts immediately (or as soon as the main window builds the sidebar menu). The terminal shows a **GLib-GIO-ERROR** and **Aborted (core dumped)**:

```text
(apk-manager:82572): GLib-GIO-ERROR **: 11:48:44.672: g_menu_item_set_detailed_action: Detailed action name '_Open APK…' has invalid format
Aborted                    (core dumped) apk-manager
```

There is no GTK dialog. The process exits because GLib treats this as a fatal programming error (`g_error`).

---

## 2. What that means

The sidebar **hamburger menu** attaches a `Gio.Menu` to a `Gtk.MenuButton`. Each item must reference a **detailed action** in a strict format, for example `win.open-apk` (action group prefix + dot + action name). That string is registered on the window via `insert_action_group("win", …)` and bound to `GLib.SimpleAction` instances named `open-apk` and `quit`.

The error says GLib tried to parse **`_Open APK…`** as the detailed action name. That string is the **menu label** (with a keyboard mnemonic underscore before “Open”), not an action. A valid detailed action never contains spaces or ellipsis; it looks like `namespace.action-name`.

So the menu was built with **label and action arguments reversed** for the Vala binding.

---

## 3. Root cause

In **C**, `g_menu_append()` is:

```c
g_menu_append (menu, detailed_action, label);
```

In **Vala**, `Gio.Menu.append` is documented as:

```vala
public void append (string label, string? action = null);
```

The code had copied the C argument order:

```vala
sidebar_menu_model.append("win.open-apk", "_Open APK…");  // wrong in Vala
```

Vala therefore passed `"win.open-apk"` as the visible label and `"_Open APK…"` as the detailed action. When GTK realized `"_Open APK…"` is not a valid action name, it called `g_error()` and the app aborted.

---

## 4. Fix applied

In `src/windows/main_window.vala`, use **label first, detailed action second**:

```vala
sidebar_menu_model.append("_Open APK…", "win.open-apk");
sidebar_menu_model.append("_Quit", "win.quit");
```

The existing `SimpleActionGroup` on prefix `"win"` and `SimpleAction` names `open-apk` / `quit` were already correct; only the menu model lines needed swapping.
