## 1. What you see

After adding list and grid views for recent APKs, switching between **list** and **grid** does not behave like AppManager:

- Icons may look wrong in one view (size unchanged, or duplicate decode work).
- Toggling view only swaps the `Gtk.Stack` page while **both** list rows and grid tiles were rebuilt every refresh, with separate ad hoc icon helpers.
- A prior “consolidation” still built **both** views on every `refresh_sessions()` and cleared a per-refresh texture map, so behavior did not match AppManager’s **one cache + one active view** model.

---

## 2. What that means

AppManager treats icons and view mode separately:

1. **One decoded paintable per app** (texture cache keyed by icon path), reused for every UI that needs that app.
2. **One `Gtk.Image` per row/cell**, each with its own `pixel_size` (list ≈ 48px, grid ≈ 96px in AppManager).
3. **`refresh_installations()`** clears the list group, then fills **either** the preferences list **or** the grid `FlowBox` according to `view_mode` — not both at once.
4. **View toggle** updates `view_mode` and calls **refresh** so the visible surface is rebuilt with the correct layout and icon size.

ApkManager had duplicated logic in `MainWindow`, rebuilt list and grid together, and did not refresh when the list/grid toggle changed — so “intelligent switching” never matched the reference app.

---

## 3. Fix applied

### 3.1 `src/utils/ui_utils.vala` (AppManager-style helper)

- Static `Gee.HashMap<string, Gdk.Paintable>` keyed by APK path.
- `load_session_icon_paintable(apk_path)` decodes once via `ApkDisplayName` + `ApkIcon`, caches the texture.
- `load_session_apk_icon(apk_path, pixel_size)` returns a new `Gtk.Image` with `set_from_paintable()` and **`pixel_size`** (list **32**, grid **64** in the sidebar).

### 3.2 `src/windows/main_window.vala`

- List rows and grid tiles both call **`UiUtils.load_session_apk_icon()`** with the appropriate constant.
- **`refresh_sessions()`** clears both containers, then populates **only** the active mode (`SessionViewMode.LIST` or `GRID`).
- **List/grid toggle handlers** set mode and call **`refresh_sessions()`** (same idea as AppManager’s view button → refresh).
