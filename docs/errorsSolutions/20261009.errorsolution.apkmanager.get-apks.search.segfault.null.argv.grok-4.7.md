## 1. What you see

**Get APKs** opens. Typing a query and starting the search closes the window and the whole application. The shell prints:

```text
Segmentation fault (core dumped)
```

The lines above that (`Running custom install script…`, `Installing apktool.jar…`) are a finished `meson install`. They copy the JAR, compile schemas, and refresh the desktop database. They are not the failure. The segfault is `apk-manager` dying on the search click.

---

## 2. What that means

`Segmentation fault` means the process read or wrote memory it does not own (signal 11). The Get APKs search downloads repository pages by spawning `curl` through `GLib.Subprocess`.

`g_subprocess_newv()` copies its argument list with `g_strdupv()`, which walks pointers until it finds a `NULL`. `HttpClient` built that list with `Gee.ArrayList.to_array()`. Gee’s array is length-prefixed only — there is no trailing `NULL`. `g_strdupv()` reads past the end of the array and the process faults.

That is the same bug already fixed for Apktool decode in `apktool_runner.vala`. Search reintroduced it in `http_client.vala`:

```vala
var argv = new Gee.ArrayList<string>();
argv.add("curl");
// ...
new Subprocess.newv(argv.to_array(), ...);  // not NULL-terminated
```

The crash happens as soon as search tries to start `curl`, before any repository HTML is parsed. The modal disappears because the application exits.

---

## 3. Fix applied

`src/utils/http_client.vala` now builds a Vala `string[]`, which the compiler NULL-terminates, and passes that array to `Subprocess.newv`:

```vala
var argv = new string[] { "curl" };
foreach (var arg in curl_args) {
    argv += arg;
}
// -A, user agent, and optional POST fields are appended the same way
new Subprocess.newv(argv, SubprocessFlags.STDOUT_PIPE | SubprocessFlags.STDERR_PIPE);
```

Search result parsers also skip a regex match that did not succeed, so a page with no hits does not call `MatchInfo.fetch` on an empty match.

---

## 4. What you should run

```bash
cd ~/Workspace/Applications/apkManager
meson compile -C build
meson install -C build
export PATH="$HOME/.local/bin:$PATH"
apk-manager
```

Open **Get APKs**, search for an app (for example `firefox`), and leave the modal open. Results from F-Droid, Aptoide, and Uptodown should appear instead of a segfault. Quit any old `apk-manager` process before launching the new binary.
