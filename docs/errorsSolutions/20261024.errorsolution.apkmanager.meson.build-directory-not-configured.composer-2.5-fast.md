## 1. What you see

Running a familiar dev command fails immediately:

```text
ERROR: Current directory is not a meson build directory: `/home/corey/Workspace/Applications/apkManager/build`.
Please specify a valid build dir or change the working directory to it.
It is also possible that the build directory was generated with an old
meson version. Please regenerate it in this case.
```

Typical commands that trigger it:

```bash
meson compile -C build
meson install -C build
```

There is no Vala compile output; Meson stops before Ninja runs.

---

## 2. What that means

Meson expects the path passed to `-C` (or the current working directory) to be a **configured build directory** — one that contains at least:

- `build.ninja`
- `meson-private/` (or legacy `meson-info/`)

Those files are created only by **`meson setup <builddir>`** against the project root.

In this repository, **`build/` is no longer exclusively a Meson output folder.** It also stores packaging layout:

| Path under `build/` | Purpose |
|---------------------|---------|
| `debian/` | Debian source metadata |
| `snap/` | Snapcraft recipe |
| `meson-debian/` | Meson tree for `.deb` builds |
| `meson-appimage/` | Meson tree for AppImage builds |
| `AppDir/` | AppImage bundle staging (after AppImage build) |

If you run `meson compile -C build` when `build/` has **no** `build.ninja`, Meson correctly reports that it is not a Meson build directory. This is not a corrupted Meson version — it is the **wrong path** for local development after the packaging layout change.

Older docs and muscle memory still say `meson setup build`, which conflicts with the new multi-purpose `build/` tree.

---

## 3. Fix

Use a **dedicated Meson subdirectory** for day-to-day development: **`build/meson/`**.

### First-time (or after wiping the dev tree)

```bash
cd ~/Workspace/Applications/apkManager
chmod +x scripts/fetch-apktool.sh
meson setup build/meson --prefix="$HOME/.local"
meson compile -C build/meson
meson install -C build/meson
update-desktop-database ~/.local/share/applications
```

### Rebuild and run

```bash
cd ~/Workspace/Applications/apkManager
meson compile -C build/meson && meson install -C build/meson
export PATH="$HOME/.local/bin:$PATH"
apk-manager
```

### Reconfigure only the dev tree

```bash
meson setup build/meson --prefix="$HOME/.local" --reconfigure
meson compile -C build/meson
meson install -C build/meson
```

### Clean dev build only (keeps packaging files)

```bash
rm -rf build/meson
meson setup build/meson --prefix="$HOME/.local"
meson compile -C build/meson
meson install -C build/meson
```

**Do not** run `rm -rf build` unless you intend to delete Debian/Snap packaging metadata under `build/debian/` and `build/snap/` as well.
