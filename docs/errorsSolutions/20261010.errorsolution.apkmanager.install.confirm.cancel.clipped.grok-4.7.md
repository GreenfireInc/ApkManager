## 1. What you see

Dragging an APK logo onto the Applications folder opens the confirmation dialog: title, icon, unverified-origin text, **Install**, then **Cancel**. **Cancel** is the blue button at the bottom. Its lower edge is cut off by the dialog. The label may still be readable, but the button is not fully inside the card.

---

## 2. What that means

`Adw.Dialog` is drawn inside its parent window, and Libadwaita will not make it taller than that window. The parent here is the Install APK window, which was `default_height: 420`.

The confirmation content is taller than that. Roughly: title, 72 px icon, a heading that wraps to several lines, the hint line, and two full-width buttons, plus margins. That stack is about 430 px before the dialog’s own frame. The extra height is taken from the bottom, so **Cancel** — the last widget — is the one that gets clipped.

`follows_content_size` only tracks the child. It does not lift the parent-window cap.

A second measurement detail made the stack taller than it needed to be: the warning label used `max_width_chars = 28`, so it wrapped to more lines than the 340 px card required. GTK then reported a height that was still short of the real wrapped height until a width was known, which is the usual height-for-width clip on the last row.

---

## 3. Fix applied

The Install APK window’s default height is **560**, so a floating dialog of this size fits inside the parent.

The dialog sets `content_height` to `-1` (natural height) and `follows_content_size` to true. The warning and hint labels have a `width_request` of 320 and a higher `max_width_chars`, so they wrap at the card width and the height request includes every line, including **Cancel**. Bottom margin stays 20 px so the button is not flush with the rounded clip.

---

## 4. What you should run

Quit ApkManager, then rebuild and install:

```bash
cd ~/Workspace/Applications/apkManager
meson compile -C build
meson install -C build
export PATH="$HOME/.local/bin:$PATH"
apk-manager 00.references/orion-store-1-5-0.apk
```

Drag the logo onto the folder. The confirmation card should show the full **Install** button and the full blue **Cancel** button, with space under Cancel.
