## 1. What you see

ApkManager launches, but the main window has no standard decorations: no title bar strip, no close / minimize / maximize buttons, and no obvious drag area. The sidebar and content may render, yet the window feels “undecorated” or hard to manage — especially on Linux Mint (Cinnamon on X11), where the compositor and window manager differ from GNOME.

Secondary dialogs such as **Open APK** and **Quick Manifest** were less affected because they already followed the correct Libadwaita layout.

---

## 2. What that means

`Adw.ApplicationWindow` does not provide a built-in system title bar. Libadwaita expects each top-level header to sit inside an `Adw.ToolbarView` so it can attach **client-side decorations** (window controls and drag region) to the window.

Before the fix, `MainWindow` placed `Adw.HeaderBar` widgets directly inside plain `Gtk.Box` containers within `Adw.NavigationSplitView`:

```text
Adw.ApplicationWindow
  └── Adw.NavigationSplitView
        ├── sidebar: Gtk.Box → Adw.HeaderBar   ← not registered with the window
        └── content: Gtk.Box → Adw.HeaderBar     ← not registered with the window
```

Libadwaita never treated those header bars as the window titlebar, so close / minimize / maximize controls were not wired. On GNOME/Wayland this can look partially acceptable; on Linux Mint / Cinnamon / X11 it often shows up as a completely undecorated frame.

The Libadwaita pattern (same as the GTK 4 book’s split-view example) wraps each pane in `Adw.ToolbarView` and adds the header with `add_top_bar()`:

```text
Adw.ApplicationWindow
  └── Adw.NavigationSplitView
        ├── sidebar: Adw.ToolbarView → top: Adw.HeaderBar, content: …
        └── content: Adw.ToolbarView → top: Adw.HeaderBar, content: …
```

`OpenWindow` and `ManifestPopup` already used that pattern; only `MainWindow` did not.

---

## 3. Fix applied

`src/windows/main_window.vala` now wraps both the sidebar and content panes in `Adw.ToolbarView`:

- Sidebar: `sidebar_toolbar.add_top_bar(sidebar_header)` with the session list below.
- Content: `content_toolbar.add_top_bar(content_header)` with the view stack below.

Libadwaita can now place window controls on the visible header bar (typically the sidebar header when the split view is expanded).

---

## 4. What you should run

```bash
cd ~/Workspace/Applications/apkManager
meson compile -C build
meson install -C build
export PATH="$HOME/.local/bin:$PATH"
apk-manager
```

The main window should show a header bar with title text and standard window buttons. If an old instance is still running, quit it before relaunching.
