## 1. What you see

Right-clicking an APK in the sidebar list or grid does nothing. There is no context menu and no terminal error. The left click still loads the APK. **Remove from recents** never appears.

---

## 2. What that means

The menu model and the `win.remove-session` action were already wired. The click never reached that code.

`Gtk.GestureClick` is a `Gtk.GestureSingle`. Its **button** property defaults to **`GDK_BUTTON_PRIMARY` (left click)**. A right click is `GDK_BUTTON_SECONDARY`. With the default, `pressed` is not emitted for a right click, so the handler that calls `PopoverMenu.popup()` never runs. Checking `get_current_button()` inside `pressed` cannot help: that signal is not delivered for the secondary button until the gesture is told to listen for it.

A second issue shows up after the first successful popup: `Gtk.Popover.set_parent()` warns and fails if the popover already has a parent. The same popover was reused for every row without `unparent()` first.

---

## 3. Fix applied

In `attach_session_context_menu()`:

1. `gesture.button = Gdk.BUTTON_SECONDARY` so only a right click starts the gesture.
2. `propagation_phase = CAPTURE` so the row receives the click before a child label or image handles it.
3. `unparent()` the shared `PopoverMenu` when it already has a parent, then `set_parent(widget)` and `popup()`.

Removing a session still only drops it from the recent list (`sessions.json`). It does not delete the APK file. If that APK was the open session, the content pane returns to the empty state.
