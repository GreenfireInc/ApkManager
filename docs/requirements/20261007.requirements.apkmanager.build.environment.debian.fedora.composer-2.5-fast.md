## 1. Summary

ApkManager is a **Vala + GTK 4 + Libadwaita** desktop application built with **Meson + Ninja**. At build time it downloads a pinned **Apktool JAR** via `scripts/fetch-apktool.sh`. At runtime, **raw APK listing** works without Java; **Apktool decode** requires a **Java 17+** runtime.

Supported primary targets:

| Distro family | Native build | Notes |
|---------------|--------------|-------|
| Debian 13 (Trixie) / Sid | Yes | Libadwaita ≥ 1.4 available |
| Ubuntu 24.04+ | Yes | Same packages as Debian |
| Fedora 40+ | Yes | Native GTK/Libadwaita toolchain |
| Debian 12 (Bookworm) | Flatpak recommended | Libadwaita may be below 1.4; use Flatpak if native build fails |

## 2. Host Environment Requirements

### 2.1 Operating system

- **64-bit Linux** (x86_64 or aarch64)
- Desktop session with D-Bus (optional but recommended for single-instance app behavior)
- Internet access **during build only** (to download Apktool JAR); runtime works offline after install

### 2.2 Build toolchain

| Tool | Minimum | Purpose |
|------|---------|---------|
| **Meson** | ≥ 0.64 | Build system (`meson.build`) |
| **Ninja** | any recent | Backend invoked by Meson |
| **Vala** | ≥ 0.56 | Compiles `.vala` sources to C |
| **GCC / Clang** | C17-capable | Compiles generated C |
| **pkg-config** | any recent | Resolves library dependencies |
| **curl** | any recent | Used by `fetch-apktool.sh` |
| **glib-compile-schemas** | GLib 2.74+ | Compiles GSettings at install |

Verify versions:

```bash
meson --version
ninja --version
valac --version
pkg-config --version
java -version    # optional at build time; required at runtime for decode
curl --version
```

### 2.3 Build-time library dependencies

| Library | Meson dependency | Purpose in ApkManager |
|---------|------------------|------------------------|
| GTK 4 | `gtk4` | Widget toolkit |
| Libadwaita | `libadwaita-1` (≥ 1.4) | GNOME-style application shell |
| GLib / GIO | `gio-2.0`, `glib-2.0` | Application lifecycle, subprocess, files |
| json-glib | `json-glib-1.0` | Session registry JSON |
| libgee | `gee-0.8` | Collections |
| libarchive | `libarchive` | Raw APK/ZIP entry listing |
| GtkSourceView 5 | `gtksourceview-5` | Future text viewers (declared in build) |
| desktop-file-utils | system package | Post-install desktop/MIME integration |

### 2.4 Runtime dependencies

| Requirement | When needed | Notes |
|-------------|-------------|-------|
| **Java runtime 17+** | Apktool decode | Raw archive browser works without Java |
| **Installed `apk-manager` binary** | Always | From `meson install` |
| **Bundled `apktool.jar`** | Decode | Installed to `<prefix>/lib/apk-manager/apktool.jar` |
| **Shared MIME database** | File-manager open | `application/vnd.android.package-archive` |

Override Apktool JAR location (development):

```bash
export APK_MANAGER_APKTOOL_JAR=/path/to/apktool.jar
```

Override install prefix detection (development):

```bash
export APK_MANAGER_PREFIX=$HOME/.local
```

## 3. Package Installation by Distro

### 3.1 Debian / Ubuntu (apt)

```bash
sudo apt update
sudo apt install -y \
  valac meson ninja-build pkg-config \
  libgtk-4-dev libadwaita-1-dev libgtksourceview-5-dev \
  libglib2.0-dev libjson-glib-dev libgee-0.8-dev \
  libarchive-dev desktop-file-utils \
  default-jre-headless git curl
```

**Java note:** `default-jre-headless` must report version **17 or newer**. Check with:

```bash
java -version
```

If Debian stable ships an older default JRE, install OpenJDK 17 explicitly:

```bash
sudo apt install openjdk-17-jre-headless
```

### 3.2 Fedora / RHEL-family (dnf)

```bash
sudo dnf install -y \
  vala meson ninja-build pkgconf-pkg-config \
  gtk4-devel libadwaita-devel gtksourceview5-devel \
  glib2-devel json-glib-devel libgee-devel \
  libarchive-devel desktop-file-utils \
  java-latest-openjdk-headless git curl
```

On RHEL, Alma, or Rocky Linux, install **EPEL** before the command above.

**Java note:** Prefer `java-latest-openjdk-headless` or any package providing JRE ≥ 17.

## 4. Build and Install Instructions

Run from the repository root (workspace-relative path shown below).

### 4.1 Standard user-local install

```bash
cd Applications/apkManager
chmod +x scripts/fetch-apktool.sh
meson setup build/meson --prefix=$HOME/.local
meson compile -C build/meson
meson install -C build/meson
```

### 4.2 Post-install desktop integration

After the first install, register the desktop entry and MIME handler:

```bash
update-desktop-database ~/.local/share/applications
glib-compile-schemas ~/.local/share/glib-2.0/schemas
gtk-update-icon-cache ~/.local/share/icons/hicolor
```

Ensure `~/.local/bin` is on your `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Add that line to `~/.bashrc` or `~/.profile` if it is not already present.

### 4.3 `build/` layout (local dev vs packaging)

| Path | Purpose |
|------|---------|
| `build/meson/` | **Local development** Meson tree (`meson setup` / `meson compile -C build/meson`) |
| `build/debian/` | Debian packaging metadata |
| `build/meson-debian/` | Meson tree created by `.deb` builds |
| `build/meson-appimage/` | Meson tree created by AppImage builds |
| `build/snap/` | Snapcraft recipe |

Do **not** use `meson compile -C build` — `build/` itself is not a Meson build directory unless it contains `build.ninja`. See [20261024.errorsolution.apkmanager.meson.build-directory-not-configured.composer-2.5-fast.md](../errorsSolutions/20261024.errorsolution.apkmanager.meson.build-directory-not-configured.composer-2.5-fast.md).

### 4.4 Clean rebuild (dev tree only)

```bash
cd Applications/apkManager
rm -rf build/meson
meson setup build/meson --prefix=$HOME/.local
meson compile -C build/meson
meson install -C build/meson
```

### 4.5 Reconfigure an existing dev build directory

```bash
cd Applications/apkManager
meson setup build/meson --prefix=$HOME/.local --reconfigure
meson compile -C build/meson
meson install -C build/meson
```

## 5. Verification Checklist

After install, confirm the following:

```bash
# Binary on PATH
which apk-manager

# Version string
apk-manager --version

# Apktool JAR bundled
test -f "$HOME/.local/lib/apk-manager/apktool.jar" && echo "apktool.jar OK"

# Desktop entry installed
test -f "$HOME/.local/share/applications/com.github.ApkManager.desktop" && echo "desktop file OK"

# Launch GUI (optional)
apk-manager

# Open an APK from CLI (optional)
apk-manager /path/to/sample.apk
```

Expected behavior:

1. **Without Java:** app launches; raw archive listing works; decode buttons show a Java-missing message.
2. **With Java 17+:** Quick Manifest and Full Decode invoke Apktool successfully.
3. **File manager:** double-clicking an `.apk` opens ApkManager after desktop database update.

## 6. Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| `meson: command not found` | Meson not installed | Install `meson` via apt/dnf (see §3) |
| `valac: command not found` | Vala not installed | Install `valac` / `vala` |
| `Dependency "libadwaita-1" not found` | Missing dev package | Install `libadwaita-1-dev` / `libadwaita-devel` |
| `Dependency "libarchive" not found` | Missing dev package | Install `libarchive-dev` / `libarchive-devel` |
| `fetch-apktool.sh` download fails | No network or blocked URL | Check curl/network; retry build |
| Decode fails immediately | Java missing or < 17 | Install JRE 17+; verify `java -version` |
| `Apktool JAR not found` | Install step skipped or wrong prefix | Re-run `meson install`; set `APK_MANAGER_PREFIX` |
| Double-click APK does nothing | Desktop DB not updated | Run `update-desktop-database` (§4.2) |
| App not on PATH | `~/.local/bin` not in PATH | Export PATH (§4.2) |

## 8. What Gets Installed

| Artifact | Typical path (`prefix=$HOME/.local`) |
|----------|--------------------------------------|
| `apk-manager` binary | `~/.local/bin/apk-manager` |
| `apktool.jar` | `~/.local/lib/apk-manager/apktool.jar` |
| Desktop entry | `~/.local/share/applications/com.github.ApkManager.desktop` |
| AppStream metadata | `~/.local/share/metainfo/com.github.ApkManager.metainfo.xml` |
| GSettings schema | `~/.local/share/glib-2.0/schemas/com.github.ApkManager.gschema.xml` |
| Application icon | `~/.local/share/icons/hicolor/scalable/apps/com.github.ApkManager.svg` |

Runtime data (created on first use):

| Path | Purpose |
|------|---------|
| `~/.local/share/apk-manager/sessions.json` | Recent APK sessions |
| `~/.cache/apk-manager/decoded/` | Decoded APK output |
| `~/.cache/apk-manager/frameworks/` | Apktool framework APKs |
